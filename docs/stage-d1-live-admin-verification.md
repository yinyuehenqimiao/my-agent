## 权限选择

- `tool:view`：只允许已授权的平台人员查看工具元数据。
- `route:simulate`：允许平台管理员、流程编辑员、流程审核员、安全管理员和审计员使用。
- 普通员工不具备后台模拟权限。
- 当前版本不支持模拟任意用户，这是有意的安全选择；需要验证他人权限时应使用预置测试账号并形成审计，而不是让前端提交任意用户 ID。

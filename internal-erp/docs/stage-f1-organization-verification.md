# 阶段 F1：独立 ERP 骨架与员工组织域

## 实现范围

- 建立独立单模块 Spring Boot 服务和独立 PostgreSQL 配置，不依赖 `my-agent` 数据库。
- 建立租户化部门、员工和员工权限表，员工档案包含工号、姓名、入职日期、状态、部门、岗位、主管和业务角色。
- 提供本人档案、司龄和本人权限三个只读 API；没有查询任意员工的公共入口。
- 司龄按“已完成周年数”计算，覆盖周年日与 2 月 29 日入职边界。
- API 身份只从服务端请求头上下文读取；服务令牌、租户、员工和链路标识任一缺失均返回稳定错误码 `ERP_UNAUTHORIZED`。
- 空服务令牌默认拒绝业务请求，健康检查不需要业务身份。
- 权限 API 返回中文业务名称，不向智能体直接暴露内部权限码。

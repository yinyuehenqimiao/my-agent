# 阶段 F2：年假余额与请假事务

## 实现内容

- 年假账户保存年度总额、已用、冻结和版本号；可用额度由 ERP 统一计算并作为 API 字段返回。
- 创建请假时通过带余额条件的原子更新冻结工作日额度，余额不足时不会生成请假单。
- 请假创建需要 `Idempotency-Key`；相同调用人、接口和请求内容只返回同一张请假单，不同内容复用同一键会被拒绝。
- 撤回只允许申请人对待主管/人事处理的单据操作，并以同一事务释放被冻结的额度。
- 提供年假余额、创建请假、查询本人请假和撤回四个 REST 接口；接口从认证上下文取得员工和租户，不接受用户指定查询对象。
- 使用 `leave_year`，避免 `year` 在 PostgreSQL/H2 中作为保留字造成迁移失败。
